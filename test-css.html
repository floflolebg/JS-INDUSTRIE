Test de chargement CSS

Test 1 - CSS Inline (doit être ROUGE)

Si cette boîte est ROUGE, le CSS inline fonctionne.

Test 2 - Style inline (doit être BLEU)

Si cette boîte est BLEUE, le style inline fonctionne.

Test 3 - CSS externe (doit être stylisé par style.css)

Si cette section utilise la classe .container de style.css, le CSS externe se charge correctement.

Instructions de diagnostic :

  1. Ouvrez cette page sur votre hébergement
  2. Ouvrez les outils de développement (F12)
  3. Allez dans l'onglet "Network" ou "Réseau"
  4. Rechargez la page (Ctrl+R)
  5. Cherchez le fichier "style.css" dans la liste
  6. Vérifiez le code HTTP (doit être 200)
  7. Vérifiez le Content-Type (doit être "text/css")

Console JavaScript

Ouvrez la console et copiez ce code :

fetch('css/style.css')
  .then(r => console.log('Status:', r.status, 'Type:', r.headers.get('content-type')))
  .catch(e => console.error('Erreur:', e))
